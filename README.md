# ДЗ 2. Bash: калькулятор и популярные города

Решение двух задач домашней работы по Linux.

- `sum.sh` принимает два целых или вещественных числа, включая отрицательные, проверяет аргументы и печатает сумму без зависимости от `bc`.
- `top-cities.sh` читает таблицу и выводит три самых популярных города в формате `количество город`.

## Запуск

```bash
chmod +x sum.sh top-cities.sh tests.sh
./sum.sh 1.5 -7
./top-cities.sh users.txt
./tests.sh
```

Нужны Bash, `awk`, `sort` и `head`. На Windows можно использовать WSL или Git Bash.
